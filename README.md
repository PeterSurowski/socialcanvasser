# Social Canvasser

TikTok automation tool for lead generation and outreach.

## Project Structure

- `/frontend` - React + TypeScript + Vite + Tailwind UI
- `/backend` - Node.js + Express API server
- `/database` - MySQL schema and migrations

## Setup

See individual README files in frontend and backend directories for setup instructions.

## Tech Stack

**Frontend:**
- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router

**Backend:**
- Node.js
- Express
- MySQL
- Puppeteer (browser automation)
- Bull (job queue)
- OpenAI API

## Development

1. Set up MySQL database
2. Install backend dependencies and run migrations
3. Install frontend dependencies
4. Start backend server
5. Start frontend dev server

## Production Deployment

Designed to run on Linux server with headless browser support.
